Place photographs belong in this folder.

Use original photographs, images supplied with permission, or assets with a
licence that permits use in the app. Add the relative asset path to the
location's image field, for example:

"image": "assets/images/places/cabarita_park.jpg"

The Explore place-details sheet supports JPG, PNG, WebP and other image formats
supported by Flutter. A remote HTTPS image URL is also supported, although a
locally bundled and properly licensed image is preferred for reliability.
