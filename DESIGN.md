# UI Style Guide

The app should feel premium.

Priorities

1. Beautiful
2. Smooth
3. Simple
4. Fast

Use

- curved panels
- glass effects where appropriate
- gradients
- soft shadows
- large cards
- rounded chips

Avoid

- square cards
- floating boxes
- cramped layouts
- unnecessary borders

The map is the hero.

The UI should support the map rather than cover it.

Sidebar should feel like a modern dashboard.

Icons should use Material Symbols Rounded.

Cards should have images where possible.

assets/images/canada_bay_logo.jpg
