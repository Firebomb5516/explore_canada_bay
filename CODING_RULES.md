# Flutter Coding Rules

Always return COMPLETE FILES.

Never tell me to replace sections.

Never return snippets unless I specifically ask.

Keep every screen responsive.

Desktop:
- side panel beside map

Mobile:
- map on top
- panel below

Never break existing functionality.

Always preserve existing JSON structures.

Do not invent new JSON formats.

Markers should always stay correctly aligned.

Do not change working marker alignment.

Avoid deprecated Flutter APIs.

Prefer Color.withValues(alpha:)

Comment code where complex.

Keep widgets small and reusable.

Use Material 3.

Do not use ugly boxy layouts.

Prefer rounded corners around 24-32px.

The app should feel similar to:

- Apple Maps
- Airbnb
- Arc Browser
- Spotify

rather than government websites.
